# 002 이미지 제작 요청서 (AI 생성용)

> 002 개편에서 **로또 가이드 상세페이지**를 풍부하게 만들기 위한 이미지 목록이다.
> 각 항목에 **복붙용 영문 프롬프트**(이미지 전용 AI 에 그대로 붙여넣기)와 **저장 경로·파일명**을 적었다.
> 최종본은 사용자가 검수한다. 파일을 `frontend/public/guide/` 에 넣어 주시면 프론트 세션이 코드에 연결한다.

---

## 왜 AI 일러스트인가 (Pexels 와의 관계)

이 사이트의 시각 언어는 **인라인 SVG 일러스트**(히어로·로고·6타일·아이콘)로 통일돼 있다. 여기에 사진(Pexels)을 섞으면 페이지마다 톤이 달라져 "성의 없고 일관성 없는" 인상을 준다(002 §디자인 의견, R35). 그래서 가이드 상세 이미지는 **브랜드 팔레트를 따르는 플랫 일러스트**로 통일하는 것을 권장한다.

- **AI 일러스트(본 문서)** — 가이드 헤더/스팟 이미지. 브랜드 색·스타일 일관성 확보. **1순위.**
- **Pexels(빌드타임 큐레이션)** — 실사 사진이 꼭 필요한 경우의 대안. `PEXELS_API_KEY` 는 `.env_frontend` 에 있고, 사용 방식·저작권 취급은 [`pexels-image-usage`](../wiki/90-external/pexels-image-usage.md) 에 있다. **인물 사진은 쓰지 않는다**(초상권·모델 릴리스 위험). 오브젝트/추상 위주.

두 경로 중 무엇을 쓰든 **한 페이지 안에서는 한 가지 스타일**로 통일한다.

## 공통 규칙 (모든 프롬프트에 이미 반영돼 있음)

- **실제 사람·얼굴을 넣지 않는다.** 손 정도의 단순 실루엣은 허용하되 사실적 인물은 금지.
- **글자·숫자 타이포를 이미지에 넣지 않는다.** (렌더 깨짐 + 금지표현 위험) 예외: 로또 볼 위의 1~2자리 숫자만 허용하며, 아래 색 규칙을 지킨다. 볼을 **무지(번호 없음)** 로 그리면 위험이 없다.
- **당첨 확률·고확률·1등 예측·당첨 보장** 같은 개념/문구를 시각적으로도 암시하지 않는다 ([`forbidden-expressions`](../wiki/40-domain/forbidden-expressions.md)).
- **실제 브랜드 로고·상표**(동행복권 로고 등)를 넣지 않는다.
- **배경 투명(PNG).** 이 사이트는 라이트/다크 모드가 있어, 배경색이 박히면 다크 모드에서 흰/검은 사각형이 뜬다(히어로에서 실제 겪은 문제). 큰 순백·순흑 덩어리를 주 실루엣으로 쓰지 말고, 어두운 배경에서도 형태가 읽히게 한다.
- **세트 일관성**: 선 굵기·채도·모서리 둥글기를 7장 모두 비슷하게. 같은 화가가 그린 한 세트처럼 보여야 한다.

### 팔레트 (프롬프트에 포함됨)

| 용도 | HEX |
|------|-----|
| 브랜드 기본(인디고) | `#3B4FD8` |
| 라벤더 배경/강조 | `#EEF0FB` · `#F5F0FC` |
| 본문/외곽선(네이비) | `#1A1D2E` |
| 보조(그레이) | `#6B7280` |
| 로또 볼 1~10 (노랑) | `#FBC400` |
| 로또 볼 11~20 (파랑) | `#69C8F2` |
| 로또 볼 21~30 (빨강) | `#FF7272` |
| 로또 볼 31~40 (회색) | `#AAAAAA` |
| 로또 볼 41~45 (초록) | `#B0D840` |

### 공통 스타일 프롬프트 조각 (STYLE BLOCK — 아래 각 프롬프트에 이미 붙여 놓음)

```
Flat vector illustration, modern friendly and minimal, soft rounded shapes, subtle
gradients, clean and uncluttered, generous padding, centered composition, consistent
medium line weight. Color palette: indigo #3B4FD8 as the primary color, soft lavender
#EEF0FB and #F5F0FC for fills, dark navy #1A1D2E for outlines used sparingly, muted
grey #6B7280 for secondary details. If lottery balls appear, color them by range:
yellow #FBC400, blue #69C8F2, red #FF7272, grey #AAAAAA, green #B0D840; balls may be
blank or show a 1-2 digit number, no other typography. No text, no words, no letters,
no logos, no brand marks. No realistic people, no faces. Transparent background, not
photorealistic. Colors that read on both light and dark backgrounds (avoid large pure
white or pure black areas).
```

## 이미지로 만들지 않는 것 (판단 근거 명시)

- **등수 판정 시각화 (R19)** — "6개 일치=1등" 같은 등수 판정은 **정지 이미지보다 기존 `LottoBall` 컴포넌트로 그리는 편이 낫다.** 맞은 볼/안 맞은 볼을 공식 색 규칙대로 실제 렌더하면 색-구간 규칙과 자동 일치하고 다크모드·접근성(`aria-label`)도 따라온다. 프론트 세션이 컴포넌트로 구현한다. → 이미지 제작 불필요.
- **뉴스 썸네일** — 백엔드가 기사 이미지를 주지 않고, 언론사 보도사진 스크래핑은 하지 않기로 결정했다([`naver-search-api`](../wiki/90-external/naver-search-api.md)). 뉴스는 텍스트 카드 + 통일 아이콘(색만 랜덤)으로 간다. → 이미지 제작 불필요.
- **주요통계·히어로** — 코드/기존 자산으로 이미 완결. 002 범위에서 새 이미지 없음.

## 사용자가 할 일 요약

1. 위 7개 프롬프트를 이미지 AI 에 붙여넣어 생성한다. (영문 프롬프트 그대로)
2. 마음에 드는 결과를 고른다. **7장의 스타일이 서로 비슷한지** 한 번에 늘어놓고 확인한다(세트 일관성).
3. 각 항목의 **저장 경로/파일명 그대로** `frontend/public/guide/` 에 넣는다.
4. 프론트 세션이 코드에 연결하고, 최종 화면을 사용자가 검수한다.
