# 요청 이미지 정보

행운상자 프론트엔드에서 **사람이 만들어 주면 좋은 이미지** 목록이다. 우선순위 순으로 적었다.

지금은 전부 코드로 그린 대체물이 들어가 있어 **하나도 없어도 화면은 완성 상태로 동작한다.** 아래는 "있으면 더 좋은 것"이고, `필수` 표시가 붙은 것만 승인·공개 전에 필요하다.

**공통 규칙**

- 파일은 `frontend/public/` 에 넣는다. 아래 각 항목의 파일명을 그대로 쓴다.
- **볼 색은 동행복권 공식 5구간을 따른다.** 시안(`메인샘플.png`)의 일러스트는 7번을 파랑으로 칠했지만 1~10은 노랑이다. 이 규칙을 어기면 사용자가 색으로 번호대를 읽는 법을 배우지 못한다 ([`0009-official-ball-colors-over-mockup`](../wiki/00-decisions/0009-official-ball-colors-over-mockup.md)).

  | 구간 | 색 | HEX |
  |------|-----|-----|
  | 1~10 | 노랑 | `#FBC400` |
  | 11~20 | 파랑 | `#69C8F2` |
  | 21~30 | 빨강 | `#FF7272` |
  | 31~40 | 회색 | `#AAAAAA` |
  | 41~45 | 초록 | `#B0D840` |

- 이미지에 **당첨 확률·고확률·1등 예측·당첨 보장** 같은 문구를 넣지 않는다 ([`forbidden-expressions`](../wiki/40-domain/forbidden-expressions.md)).
- 브랜드 색: 기본 `#3B4FD8`, 히어로 배경 그라디언트 `#EEF0FB` → `#F5F0FC`, 본문 `#1A1D2E`, 보조 텍스트 `#6B7280`.
- 파일을 주시면 제가 코드에 연결하고 대체물을 제거하겠습니다. **파일명만 맞춰 주시면 됩니다.**

## 1. 히어로 일러스트 (권장)

홈 첫 화면 오른쪽의 로또 추첨기 그림. 시안의 3D 렌더가 이 자리다.

| 항목 | 값 |
|------|-----|
| 파일명 | `public/hero-lotto-machine.png` |
| 크기 | **840 × 760 px** (표시 크기 420×380 의 2배. 레티나 대응) |
| 형식 | **PNG, 배경 투명** |
| 용량 | 200 KB 이하 권장 |
| 추가(선택) | `public/hero-lotto-machine.webp` 를 함께 주면 우선 사용 |

**내용**: 투명한 유리구 안에 로또 볼이 담겨 있고, 아래에 `LOTTO 6/45` 가 새겨진 받침대가 있다. 주변에 색종이 조각이 흩날린다. 시안과 같은 구도다.

**주의할 점**

- 배경을 **반드시 투명**하게 해 주세요. 히어로 배경이 라이트/다크에서 달라지므로 이미지가 배경색을 갖고 있으면 다크 모드에서 흰 사각형이 뜹니다.
- 볼에 번호를 넣는다면 위 5구간 색 규칙을 지켜 주세요. 예: `7`(노랑) `14`(파랑) `24`(빨강) `33`(회색) `42`(초록).
- 번호를 넣기 어렵다면 **번호 없는 무지 볼**도 괜찮습니다. 그 편이 규칙 위반 위험이 없습니다.
- 다크 모드에서도 보이므로 흰색 하이라이트만으로 형태를 잡지 마시고, 외곽선이 어두운 배경에서도 읽히게 해 주세요.

**지금 들어가 있는 것**: 인라인 SVG 로 그린 유리구 + 볼 6개 + 받침대(`frontend/src/components/HeroArt.tsx`). 토큰을 참조해 다크 모드와 공식 볼 색을 자동으로 따릅니다. **교체하지 않아도 됩니다.** 3D 렌더 특유의 질감이 필요할 때만 주세요.

## 2. 로고 (권장)

헤더 좌상단과 푸터에 쓰입니다.

| 항목 | 값 |
|------|-----|
| 파일명 | `public/logo.svg` (기존 파일 교체) |
| 형식 | **SVG** (벡터). 어려우면 `logo.png` 512×512, 투명 배경 |
| 표시 크기 | 헤더에서 28×28 px 로 줄여 그립니다 |

**주의**: 28px 로 줄었을 때 형태가 뭉개지지 않아야 합니다. 획이 가늘거나 요소가 4개를 넘으면 알아볼 수 없게 됩니다.

**지금 들어가 있는 것**: 파란 라운드 사각형 안에 볼 4개(`public/logo.svg`), 그리고 헤더에는 글자 `행` 을 쓰는 마크. 파비콘(`src/app/icon.svg`)도 같은 도형입니다. 로고를 새로 주시면 파비콘도 함께 맞추겠습니다.

## 만들지 않아도 되는 것

- **뉴스 썸네일** — 백엔드가 이미지 URL 을 주지 않습니다. 목록은 제목·출처·발행일·요약·키워드로 구성됩니다.
- **배경 패턴·텍스처** — 히어로 그라디언트 외에 배경 이미지를 쓰지 않습니다. 용량 대비 얻는 것이 없습니다.
- **아이콘 세트** — 6타일과 UI 아이콘은 전부 인라인 SVG 로 그렸습니다(`frontend/src/components/icons.tsx`). 색을 CSS 토큰에서 상속받으므로 다크 모드와 브랜드 색 변경을 자동으로 따릅니다. 이모지는 OS 마다 모양이 달라 쓰지 않습니다.
