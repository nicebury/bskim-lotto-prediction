# 작업지시초안: 로또/복권 데이터 대시보드 서비스 기획 및 개발 방향

## 1. 문서 목적

본 문서는 로또 관련 정보 제공 사이트의 초기 기획 및 개발 방향을 정리한 작업지시 초안이다.  
이 문서는 Claude Code 또는 개발 보조 도구에 전달하여 상세 개발 계획, 화면 설계, 데이터 설계, API 설계, SEO 설계, 애드센스 대응 계획을 다시 수립하기 위한 기준 문서로 사용한다.

본 서비스는 초기 단계에서 로그인 없이 운영한다.  
사용자 계정, 회원가입, 개인정보 기반 개인화 기능은 MVP 범위에서 제외한다.

가장 중요한 목표는 다음과 같다.

1. 검색엔진에 잘 노출될 수 있는 정보형 사이트 구조를 만든다.
2. Google AdSense 심사에 불리하지 않은 콘텐츠 품질과 사이트 정책 구조를 만든다.
3. 사용자가 처음 접속했을 때 최신 로또 정보, 통계, 뉴스, 재미용 추천 기능을 자연스럽게 탐색하게 만든다.
4. 당첨 보장, 구매 유도, 복권 구매 대행처럼 보이지 않도록 서비스 포지션을 명확히 한다.
5. 향후 연금복권, 스피또, 복권 뉴스, 꿈해몽 콘텐츠로 확장 가능한 구조를 만든다.

## 2. 서비스 포지셔닝

본 서비스는 다음 성격의 사이트로 기획한다.

- 복권 정보 제공 사이트
- 로또 당첨결과 확인 사이트
- 로또 번호 통계 분석 사이트
- 복권 관련 뉴스/데이터 대시보드
- 재미용 번호 추천 시뮬레이터
- 꿈해몽 기반 재미용 번호 추천 서비스

본 서비스는 다음 성격으로 보이면 안 된다.

- 당첨 예측 사이트
- 고확률 당첨번호 제공 사이트
- 당첨 보장 사이트
- 유료 번호 판매 사이트
- 복권 구매 대행 사이트
- 온라인 복권 판매 사이트
- 사행성 조장 사이트

서비스 내 모든 추천 기능은 반드시 다음 관점으로 표현한다.

> 과거 당첨번호 통계와 랜덤 알고리즘을 활용한 참고용/재미용 시뮬레이션이며, 당첨을 보장하지 않는다.

## 3. 핵심 운영 전략

초기에는 로또 6/45에 집중한다.  
연금복권, 스피또, 기타 복권 콘텐츠는 향후 확장 가능성을 고려하되, MVP에서 무리하게 구현하지 않는다.

다만 메인홈에는 향후 확장 가능한 서비스 카드 형태로 다음 항목을 보여줄 수 있다.

- 로또 6/45: 활성화
- 번호 통계: 활성화
- 번호 추천: 활성화
- 꿈해몽 추천: 활성화
- 복권 뉴스: 활성화 또는 2차 구현
- 연금복권: 준비 중
- 스피또: 준비 중

준비 중 콘텐츠는 빈 페이지로 만들지 않는다.  
준비 중 페이지를 만들 경우에도 최소한 다음 정도의 안내 문구를 제공한다.

> 연금복권 데이터 대시보드는 준비 중입니다. 현재는 로또 6/45 당첨결과, 번호 통계, 재미용 번호 추천 기능을 먼저 제공합니다.

애드센스 관점에서 빈 페이지, 공사 중 페이지, 단순 이동용 페이지는 부정적으로 작용할 수 있으므로 광고 게재 대상에서 제외하거나, 충분한 본문 콘텐츠가 있을 때만 노출한다.

## 4. 기술 방향

### 4.1 프론트엔드

프론트엔드는 React 기반으로 개발하되, SEO와 애드센스 심사를 고려하여 Next.js 사용을 권장한다.

권장 방향:

- Next.js 기반 프론트엔드
- SSR 또는 SSG 적극 활용
- 회차별 상세 페이지, 통계 상세 페이지, 가이드 페이지는 검색엔진이 HTML 본문을 바로 읽을 수 있도록 구성
- 클라이언트 렌더링만으로 주요 콘텐츠를 노출하지 않도록 주의
- 페이지별 title, description, canonical, Open Graph, JSON-LD를 구성

피해야 할 방향:

- index.html 하나만 있는 순수 CSR SPA
- API 호출 후 브라우저에서만 본문 콘텐츠가 생성되는 구조
- 검색엔진이 읽을 수 있는 텍스트가 거의 없는 대시보드
- 아이콘만 있고 설명 본문이 없는 홈 화면

### 4.2 백엔드

백엔드는 FastAPI 사용을 전제로 한다.

FastAPI의 역할:

- 로또 회차 데이터 수집 및 제공
- 회차별 당첨번호 API 제공
- 등위별 당첨금/당첨자 수 데이터 제공
- 번호 통계 계산 API 제공
- 추천번호 시뮬레이션 API 제공
- 꿈해몽 키워드 기반 추천 API 제공
- 뉴스 수집/큐레이션 데이터 제공
- 사이트맵 생성에 필요한 최신 회차/콘텐츠 목록 제공

프론트와 백엔드 역할을 다음과 같이 분리한다.

- Next.js: 화면 렌더링, SEO 메타데이터, 정적/서버 렌더링 페이지 구성
- FastAPI: 데이터 수집, 데이터 정제, 분석 계산, API 제공

## 5. 전체 정보 구조

상세 폴더 구조보다는 URL과 페이지 역할 기준으로 구조를 잡는다.

### 5.1 기본 페이지 구조

- `/`  
  메인홈. 사이트 전체의 허브 역할.

- `/lotto`  
  로또 대시보드. 최신 회차 정보, 주요 통계, 추천 진입점을 제공.

- `/lotto/latest`  
  최신 로또 당첨결과 페이지.

- `/lotto/round/{roundNo}`  
  회차별 상세 페이지. SEO 유입 핵심 페이지.

- `/lotto/stat`  
  로또 번호 통계 메인.

- `/lotto/stat/hot-cold`  
  많이 나온 번호, 적게 나온 번호, 오래 안 나온 번호.

- `/lotto/stat/frequency`  
  번호별 출현 빈도.

- `/lotto/stat/pattern`  
  홀짝, 고저, 합계, 연속번호, 끝수, 번호대 분포.

- `/lotto/recommend`  
  재미용 로또 번호 추천 시뮬레이터.

- `/dream`  
  꿈해몽 번호 추천 메인.

- `/dream/{keyword}`  
  돼지꿈, 돈꿈, 불꿈, 물꿈 등 꿈 키워드별 상세 페이지.

- `/news`  
  복권 뉴스/이슈 큐레이션.

- `/guide`  
  복권 이용 가이드 허브.

- `/guide/how-to-check`  
  로또 당첨번호 확인 방법.

- `/guide/prize-claim`  
  로또 당첨금 수령 방법.

- `/guide/lotto-rule`  
  로또 기본 규칙.

- `/guide/auto-vs-manual`  
  자동/수동 선택 차이 안내.

- `/guide/responsible-lottery`  
  건전한 복권 이용 안내.

- `/privacy`  
  개인정보처리방침.

- `/terms`  
  이용약관.

- `/disclaimer`  
  면책 고지.

- `/contact`  
  문의 페이지.

## 6. 메인홈 기획

메인홈은 단순 앱 런처처럼 아이콘만 배치하지 않는다.  
아이콘형 바로가기는 사용하되, 최신 데이터 요약, 통계 요약, 뉴스, 가이드 콘텐츠가 함께 존재해야 한다.

메인홈의 역할은 다음과 같다.

1. 사용자가 사이트 성격을 즉시 이해하게 한다.
2. 최신 로또 정보를 빠르게 확인하게 한다.
3. 번호 통계와 추천 기능으로 자연스럽게 이동시킨다.
4. 검색엔진이 읽을 수 있는 충분한 텍스트 콘텐츠를 제공한다.
5. 애드센스 심사 시 저가치/빈 페이지로 보이지 않게 한다.

### 6.1 메인홈 권장 섹션

#### 1단: 히어로 영역

예시 문구:

> 복권 데이터를 한눈에 보는 로또 인사이트  
> 최신 로또 당첨결과, 번호 통계, 복권 뉴스, 재미용 번호 추천을 한 곳에서 확인하세요.

권장 CTA:

- 최신 로또 결과 보기
- 번호 통계 보기
- 번호 추천 시뮬레이션

사용하지 말아야 할 CTA:

- 구매하기
- 당첨번호 받기
- 1등 번호 보기
- 고확률 번호 받기
- 프리미엄 당첨번호

#### 2단: 아이콘형 바로가기

아이콘형 메뉴는 사용하되, 각 아이콘에는 짧은 설명을 붙인다.

예시:

- 로또 6/45: 최신 당첨결과와 회차별 정보를 확인합니다.
- 번호 통계: 최근 많이 나온 번호와 오래 안 나온 번호를 분석합니다.
- 번호 추천: 랜덤/통계 기반 재미용 번호를 생성합니다.
- 꿈해몽 추천: 꿈 키워드를 바탕으로 재미용 번호를 생성합니다.
- 복권 뉴스: 최근 복권 관련 이슈를 확인합니다.
- 연금복권: 준비 중입니다.

#### 3단: 오늘의 로또 요약

최신 회차 정보를 카드 형태로 보여준다.

포함 정보:

- 회차 번호
- 추첨일
- 당첨번호 6개
- 보너스 번호
- 1등 당첨자 수
- 1등 1게임당 당첨금
- 다음 추첨 D-Day 또는 추첨 일정

단순 데이터 표시에서 끝내지 말고 짧은 해석 문장을 붙인다.

예시:

> 최근 20회 기준 33번은 출현 빈도가 높은 편입니다. 다만 과거 출현 빈도는 다음 회차 당첨을 보장하지 않습니다.

#### 4단: 주요 통계 카드

- 최근 20회 HOT 번호
- 최근 20회 COLD 번호
- 오래 안 나온 번호
- 번호별 출현 빈도
- 홀짝 비율
- 고저 비율
- 번호 합계 분포
- 동반 출현 번호

각 카드는 상세 통계 페이지로 연결한다.

#### 5단: 추천 시뮬레이터 진입

메인에서는 추천번호를 과하게 노출하지 않고, 체험 카드 형태로 제공한다.

예시:

> 오늘의 재미용 추천번호를 생성해보세요.  
> 추천 기준: 랜덤 + 번호대 균형 + 최근 통계 참고

반드시 고지 문구를 함께 표시한다.

> 추천번호는 통계와 랜덤 알고리즘을 활용한 참고용 시뮬레이션입니다. 당첨을 보장하지 않습니다.

#### 6단: 복권 뉴스

뉴스는 제목만 나열하지 말고, 가능하면 다음 정보를 포함한다.

- 제목
- 출처
- 발행일
- 짧은 요약
- 관련 키워드

뉴스 콘텐츠는 원문 복제보다 큐레이션/요약/분류 중심으로 구성한다.

#### 7단: 가이드 콘텐츠

SEO와 애드센스 심사를 위해 가이드 콘텐츠를 홈 하단에 노출한다.

예시:

- 로또 당첨번호 확인 방법
- 로또 당첨금 수령 방법
- 로또 번호 통계 보는 법
- 자동과 수동의 차이
- 추천번호는 왜 참고용이어야 할까
- 건전한 복권 이용 안내

## 7. 로또 대시보드 기획

`/lotto` 페이지는 메인홈보다 데이터 중심으로 구성한다.  
다만 과도한 카드 배치는 피하고, 사용자가 가장 관심 있어 하는 정보를 우선 배치한다.

### 7.1 권장 구성

상단:

- 최신 회차 당첨번호
- 보너스 번호
- 추첨일
- 1등 당첨자 수
- 1등 당첨금
- 다음 추첨 일정

중단:

- 최근 20회 HOT 번호
- 최근 20회 COLD 번호
- 오래 안 나온 번호
- 번호 출현 빈도 차트

하단:

- 홀짝/고저/합계 패턴 요약
- 재미용 추천번호 생성 카드
- 꿈해몽 추천 진입 카드
- 최근 복권 뉴스
- 당첨 판매점 요약 또는 준비 중 영역

### 7.2 UX 기준

- 첫 화면에서 모든 것을 보여주려 하지 않는다.
- 카드 수를 줄이고 “자세히 보기”로 상세 페이지 이동을 유도한다.
- 숫자 정보는 시각적으로 잘 보이게 하되, 예측처럼 표현하지 않는다.
- 모바일에서는 차트보다 요약 카드 중심으로 구성한다.

## 8. SEO용 상세 콘텐츠 계획

대시보드는 체류시간을 만들고, 상세 페이지는 검색 유입을 담당한다.

### 8.1 회차 상세 페이지

URL 예시:

- `/lotto/round/1184`

페이지 제목 예시:

- `제1184회 로또 당첨번호와 1등 당첨금 | 로또인사이트`

본문 구성:

- 회차 번호
- 추첨일
- 당첨번호
- 보너스 번호
- 등위별 당첨자 수
- 등위별 당첨금
- 1등 당첨 판매점
- 이번 회차 번호 패턴
- 최근 20회 기준 비교
- 관련 회차 링크
- 면책 고지

중요한 점:

- 회차별 페이지는 누적될수록 SEO 자산이 된다.
- 모든 회차 페이지에 동일한 템플릿만 반복하지 말고, 각 회차별 패턴 분석 문장을 자동 생성하거나 수동 보강한다.
- 단순 표만 있는 페이지로 만들지 않는다.

### 8.2 통계 상세 페이지

주요 페이지:

- `/lotto/stat/hot-cold`
- `/lotto/stat/frequency`
- `/lotto/stat/pattern`

포함해야 할 내용:

- 최근 20회 기준
- 최근 50회 기준
- 최근 100회 기준
- 보너스 번호 포함/제외 옵션
- 표와 차트
- 통계 해석 문장
- 통계 사용 시 주의사항

주의 문구:

> 로또 번호는 무작위로 추첨되므로 과거 통계가 향후 당첨을 보장하지 않습니다. 본 통계는 과거 회차의 분포를 이해하기 위한 참고 정보입니다.

### 8.3 추천번호 시뮬레이터 페이지

URL:

- `/lotto/recommend`

추천 방식:

- 완전 랜덤
- 최근 HOT 번호 일부 반영
- 최근 COLD 번호 일부 반영
- 홀짝 균형형
- 번호대 균형형
- 합계 범위 균형형

결과 표시:

- 추천번호 6개
- 홀짝 비율
- 고저 비율
- 번호 합계
- 번호대 분포
- 최근 HOT 번호 포함 개수
- 최근 COLD 번호 포함 개수
- 연속번호 포함 여부

금지 표현:

- 예상 적중 확률
- 1등 가능성
- 당첨 확률 상승
- 고확률 번호
- 검증된 번호

권장 표현:

- 조합 성향
- 추천 기준
- 통계 참고 요소
- 랜덤 보정
- 재미용 시뮬레이션

### 8.4 꿈해몽 페이지

주요 페이지:

- `/dream`
- `/dream/pig`
- `/dream/money`
- `/dream/fire`
- `/dream/water`
- `/dream/ancestor`

페이지 구성:

- 꿈 키워드 설명
- 일반적인 꿈해몽 의미
- 관련 키워드
- 재미용 번호 생성 버튼
- 추천번호 결과
- 비슷한 꿈 키워드
- 면책 고지

주의:

- 꿈해몽과 당첨 사이의 인과관계를 주장하지 않는다.
- “돼지꿈이면 로또 당첨”처럼 확정적으로 표현하지 않는다.
- 재미/오락용 콘텐츠로 명확히 표현한다.

### 8.5 가이드 페이지

애드센스 심사와 사이트 신뢰도 향상을 위해 반드시 준비한다.

초기 필수 가이드:

- 로또 당첨번호 확인 방법
- 로또 당첨금 수령 방법
- 로또 기본 규칙
- 자동과 수동의 차이
- 로또 번호 통계 보는 법
- 추천번호 시뮬레이터 사용법
- 건전한 복권 이용 안내

가이드 페이지는 API 데이터와 별도로 본문 콘텐츠가 충분해야 한다.

## 9. 로그인 없는 사용자 경험 설계

초기 서비스는 로그인 없이 제공한다.

로그인이 없기 때문에 서버에 사용자 개인정보를 저장하지 않는다.  
대신 브라우저 localStorage를 활용해 다음 기능을 제공할 수 있다.

- 최근 생성한 번호 저장
- 사용자가 저장한 번호 세트
- 최근 본 회차
- 꿈해몽 최근 검색어
- 선호 통계 기간

사용자에게는 다음과 같이 안내한다.

> 저장한 번호는 현재 브라우저에만 보관됩니다. 브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 저장 정보가 유지되지 않을 수 있습니다.

서버에 저장하지 않는 것을 명확히 안내하면 개인정보 부담을 낮출 수 있다.

## 10. 체류시간 유도 기능

사용자가 오래 머무르게 하려면 단순 번호 출력이 아니라 “번호를 해석해주는 경험”이 필요하다.

### 10.1 추천번호 생성 후 분석 제공

번호 생성 후 다음 정보를 함께 보여준다.

- 홀짝 비율
- 고저 비율
- 번호 합계
- 번호대 분포
- 최근 HOT 번호 포함 개수
- 최근 COLD 번호 포함 개수
- 최근 20회 당첨번호와 겹친 횟수
- 연속번호 포함 여부
- 끝수 패턴

예시 문장:

> 생성된 조합은 홀짝 3:3, 고저 2:4 구성입니다. 최근 20회 HOT 번호가 2개 포함되어 있으며, 연속번호는 포함되지 않았습니다.

### 10.2 내 번호 비교 기능

로그인 없이 입력한 번호를 최신 회차와 비교한다.

기능:

- 내 번호 입력
- 최신 회차와 일치 개수 표시
- 최근 10회와 일치 개수 표시
- 번호 저장은 localStorage 사용

### 10.3 공유 기능

- 추천번호 이미지 저장
- 카카오톡/문자 공유용 텍스트 복사
- 회차 결과 공유

공유 문구에도 당첨 보장 표현을 넣지 않는다.

## 11. 애드센스 대응 기준

애드센스 통과를 보장할 수는 없다.  
다만 다음 기준을 충족하면 심사에서 불리할 가능성을 줄일 수 있다.

### 11.1 필수 정책/정보 페이지

다음 페이지를 반드시 만든다.

- 개인정보처리방침
- 이용약관
- 면책 고지
- 문의 페이지

개인정보처리방침에는 다음 내용을 포함한다.

- 수집하는 정보
- 수집 목적
- 보유 기간
- 쿠키 사용 여부
- Google AdSense 및 제3자 광고 사업자의 쿠키 사용 가능성
- 광고 개인화 관련 안내
- 사용자의 선택권
- 문의처

로그인이 없어도 서버 로그, 쿠키, 광고 식별자, Google Analytics, AdSense 등으로 인해 개인정보/쿠키 안내가 필요할 수 있다.

### 11.2 콘텐츠 품질 기준

애드센스 신청 전 최소 콘텐츠 기준을 다음과 같이 잡는다.

권장 최소 구성:

- 회차 상세 페이지 20개 이상
- 통계 상세 페이지 3~5개 이상
- 가이드 페이지 5~10개 이상
- 꿈해몽 키워드 페이지 10개 이상
- 뉴스/큐레이션 페이지 1개 이상
- 메인홈과 로또 대시보드에 충분한 본문 설명 포함

피해야 할 상태:

- API 데이터만 표로 출력하는 사이트
- 뉴스 제목만 복사해 나열한 사이트
- 아이콘만 있는 메인홈
- 빈 페이지 또는 준비 중 페이지 다수
- 광고 영역이 콘텐츠보다 많은 페이지
- 중복 템플릿만 반복되는 회차 페이지
- 본문이 거의 없는 대시보드

### 11.3 복권/도박 관련 리스크 관리

복권 관련 콘텐츠는 광고 제한 주제로 분류될 가능성이 있으므로 다음을 지킨다.

금지:

- 온라인 복권 구매 유도
- 복권 구매 대행
- 유료 번호 판매
- 당첨 보장
- 고확률 표현
- 1등 예측 표현
- 카지노/도박 사이트 제휴 링크
- 구매 버튼 또는 결제 유도

권장:

- 공식 당첨결과 확인
- 회차별 데이터 정리
- 번호 통계 분석
- 재미용 번호 추천
- 건전한 복권 이용 안내
- 19세 미만 구매 불가 안내
- 책임 있는 이용 안내

### 11.4 광고 배치 기준

애드센스 승인 전에는 광고 영역을 과하게 노출하지 않는다.  
승인 후에도 다음 기준을 지킨다.

- 광고가 콘텐츠를 가리지 않도록 한다.
- 버튼, 메뉴, 번호 생성 영역 바로 옆에 오해될 수 있게 배치하지 않는다.
- 광고가 내비게이션이나 액션 버튼처럼 보이지 않도록 한다.
- 콘텐츠보다 광고가 더 많아 보이지 않게 한다.
- 추천번호 생성 버튼 주변에 광고를 과도하게 배치하지 않는다.

## 12. SEO 대응 기준

### 12.1 기술 SEO

모든 주요 페이지에 다음을 적용한다.

- 고유한 title
- 고유한 meta description
- canonical URL
- Open Graph title/description/image
- JSON-LD 구조화 데이터
- breadcrumb
- sitemap.xml
- robots.txt
- 정상 HTTP status code
- 모바일 반응형
- HTTPS
- 빠른 로딩 속도
- 이미지 alt 텍스트
- 내부 링크 구조

### 12.2 페이지별 메타 예시

회차 상세 페이지:

```text
Title: 제1184회 로또 당첨번호와 1등 당첨금 | 로또인사이트
Description: 제1184회 로또 당첨번호, 보너스 번호, 1등 당첨자 수, 당첨금, 번호 패턴 분석을 확인해보세요.
```

통계 페이지:

```text
Title: 최근 20회 로또 많이 나온 번호와 안 나온 번호 | 로또인사이트
Description: 최근 20회 로또 당첨번호를 기준으로 많이 나온 번호, 적게 나온 번호, 오래 안 나온 번호, 번호별 출현 빈도를 확인해보세요.
```

추천 페이지:

```text
Title: 로또 번호 추천 시뮬레이터 | 로또인사이트
Description: 랜덤, 번호대 균형, 최근 통계 참고 방식으로 재미용 로또 번호를 생성하고 조합 성향을 분석해보세요.
```

꿈해몽 페이지:

```text
Title: 돼지꿈 로또 번호 추천 | 재미용 꿈해몽 번호 생성
Description: 돼지꿈의 일반적인 의미를 확인하고, 꿈 키워드를 바탕으로 재미용 로또 번호를 생성해보세요. 당첨을 보장하지 않습니다.
```

### 12.3 콘텐츠 SEO

검색 유입은 메인홈보다 상세 페이지가 담당한다.

우선 타깃 키워드:

- 로또 당첨번호
- 로또 최신 당첨번호
- 로또 1184회 당첨번호
- 로또 1등 당첨금
- 로또 많이 나온 번호
- 로또 안 나온 번호
- 로또 오래 안 나온 번호
- 로또 번호 통계
- 로또 번호 추천
- 로또 꿈해몽 번호
- 돼지꿈 로또번호
- 돈꿈 로또번호
- 로또 당첨금 수령 방법
- 로또 자동 수동 차이

각 페이지는 특정 검색 의도 하나를 명확히 담당해야 한다.

### 12.4 구조화 데이터

가능한 구조화 데이터:

- Organization
- WebSite
- BreadcrumbList
- Article 또는 BlogPosting: 가이드/뉴스/꿈해몽 콘텐츠
- Dataset: 번호 통계 데이터 설명 페이지에서 검토 가능
- FAQPage: 실제 FAQ가 충분할 때만 사용

주의:

- 페이지에 실제로 보이지 않는 내용을 구조화 데이터에 넣지 않는다.
- 검색 결과를 조작하기 위한 과장 마크업을 넣지 않는다.
- 리뷰/평점 구조화 데이터는 실제 사용자 리뷰가 없으면 사용하지 않는다.

## 14. 콘텐츠 발행 전략

### 14.1 자동 생성 콘텐츠

매주 추첨 후 자동 생성 또는 갱신한다.

- 최근 100회 통계
- HOT/COLD 번호
- 패턴 분석 문장

### 14.2 수동 또는 반자동 콘텐츠

애드센스와 SEO 강화를 위해 다음 콘텐츠는 별도 작성한다.

- 로또 기본 가이드
- 당첨금 수령 방법
- 번호 통계 보는 법
- 추천번호 시뮬레이터 사용법
- 자동/수동 차이
- 건전한 복권 이용 안내
- 꿈해몽 키워드 콘텐츠

### 14.3 콘텐츠 작성 원칙

- 단순 복사 금지
- 공식 데이터는 출처를 명확히 표시
- 뉴스는 원문 복제보다 요약/분류/키워드 중심
- 통계 페이지에는 해석 문장을 포함
- 추천 페이지에는 면책 문구를 포함
- 반복 템플릿 페이지라도 회차별 차별화 문장을 포함

## 15. 화면 톤앤매너

참고 방향:

- 토스증권 같은 깔끔한 정보형 대시보드 분위기
- 단, 특정 서비스의 디자인을 그대로 복제하지 않는다.
- 흰색 배경, 부드러운 카드, 간결한 차트, 명확한 숫자 강조
- 과도한 색상과 복잡한 카드 배치를 피한다.
- 모바일에서는 앱처럼 빠르게 탐색 가능하게 한다.

디자인 원칙:

- 첫 화면은 쉽고 직관적이어야 한다.
- 번호 공, 회차, 당첨금 등 핵심 숫자는 명확히 보인다.
- 추천 기능은 재미있게 보이되 과장하지 않는다.
- 통계 정보는 신뢰감 있게 보인다.
- 광고 영역이 콘텐츠 경험을 방해하지 않는다.

## 17. 개발 시 반드시 피해야 할 것

- 로그인/회원가입을 MVP에 포함하지 않는다.
- 사용자 개인정보를 불필요하게 수집하지 않는다.
- 추천번호 생성 이력을 서버에 개인 단위로 저장하지 않는다.
- `구매하기` 버튼을 만들지 않는다.
- `당첨확률`, `예상 적중률`, `고확률` 같은 표현을 쓰지 않는다.
- 복권 구매 대행처럼 보이는 기능을 만들지 않는다.
- 광고를 콘텐츠보다 더 크게 보이게 하지 않는다.
- 빈 페이지, 공사 중 페이지에 광고를 노출하지 않는다.
- 단순 API 데이터 출력만으로 페이지를 구성하지 않는다.
- 뉴스 원문을 무단 복제하지 않는다.
- 디자인 레퍼런스를 그대로 복제하지 않는다.

## 20. 최종 방향 요약

본 서비스는 “로또 번호 추천 사이트”가 아니라 “로또 데이터와 복권 정보를 한눈에 보는 정보형 대시보드”로 기획한다.

핵심 구조는 다음과 같다.

- 메인홈: 복권 정보 허브
- 로또 대시보드: 최신 정보와 주요 통계 요약
- 회차 상세 페이지: SEO 유입 핵심
- 통계 상세 페이지: 체류시간과 검색 유입 핵심
- 추천 시뮬레이터: 재미 요소와 재방문 유도
- 꿈해몽 콘텐츠: 롱테일 SEO 확장
- 가이드 콘텐츠: 신뢰도와 애드센스 대응

초기에는 로그인 없이 운영하고, 사용자 정보는 수집하지 않는다.  
내 번호 저장 등은 localStorage를 활용한다.

가장 중요한 원칙은 다음과 같다.

> 정보 제공, 통계 분석, 재미용 시뮬레이션에 집중하고, 당첨 보장·구매 유도·고확률 표현은 절대 사용하지 않는다.
