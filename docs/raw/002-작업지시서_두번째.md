# 작업지시서 두번째

##목적
작업시지서초안_보완 버전으로 만들어진 싸이트에 대해 수정작업을 실행한다.

##공통규칙
1. 작업지시서를 정독하여 분석한다.
2. 내가 어떤 요구를 하고 있는지, 기획 설계자, 디자이너(UI/UX), 사이트 사용자 관점에서 분석한다.
 -사이트 사용자의 연령은 다양하겠지만 40이상을 염두해 둔다.
3. 기능에 대해서 정의하고, 화면상에 어떻게 구현할 것인가에 대해서 설계하고 plan을 마련한다. 
3. 이 요구를 처리하기 위해서 Worker, 백엔드, 프론트 세션에서 각자 어떤 일을 해야 하는지 분류한다.
4. 각자가 해야 할 일을 wiki에 적용한다. 
다시한번 말하지만 Worker, 백엔드, 프론트가 각각의 세션에서 독립적으로 병렬로 수행됨을 고려해야 한다.
5. wiki 작업이 완료되면 각각의 세션에 수행명령은 내가 직접할 예정(각각 동시에 실행.)

    저작권에 문제 없는 이미지를 찾아서 넣어서 활용해. 그렇다고 이미지를 너무 남발해서 지저분하게 하지는 말고.

   -전체적인 디자인인이 조금 성의 없어 보이는 경향이 있음. 화려할 필요는 없지만 조금더 신경써 주기바람.
   -전체적인 디자인의 일관성을 해치면 안됨 (페이지별로 너무 상이한 디자인 사용등은 지양)
