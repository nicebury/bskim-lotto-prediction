# 사이트명 상표 확인 — 행운상자

사이트명은 **"행운상자"** 로 확정됐다. 이 페이지는 그 이름의 상표·검색 리스크를 정리한다. 이름 결정 자체의 근거는 `[[0007-site-name-haengunsangja]]`.

**아직 신뢰할 수 없다(`status: draft`).** KIPRIS 상표 검색과 도메인 확보가 미결이다.

## 웹 검색 결과 (확인됨)

- **"행운상자" 와 동일한 서비스·도메인은 발견되지 않았다.**
- 아이템매니아의 이벤트명("매니아 행운 상자") 용례가 있으나 **서비스명 충돌은 아니다.**

## "행운복권상자" 대비 개선점

당초 후보는 "행운복권상자"였다. 명칭에서 **"복권"이 빠지면서 판매 사이트로 오인될 리스크가 줄었다.**

국내에서 복권 판매는 동행복권(dhlottery.co.kr) **단일 채널만 합법**이며, 사칭 사기가 증가하는 상황이다(출처: [오마이뉴스](https://www.ohmynews.com/NWS_Web/View/at_pg.aspx?CNTN_CD=A0003176306)). "복권 구매 대행처럼 보이면 안 된다"는 초안 2장·17장의 포지셔닝 원칙과 정합한다.

## 남는 약점

"행운상자"는 일반명사 조합이라 **브랜드 검색 유입이 약하다.** 다만 주 유입 경로는 사이트명이 아니라 회차·통계 롱테일 키워드(예: `로또 1184회 당첨번호`, `로또 오래 안 나온 번호`)로 이미 설계돼 있어 **전략상 문제는 없다.** 사이트명 자체로는 검색 트래픽을 기대하지 않는다.

## 미확인 (사람이 직접 확인해야 함)

- **KIPRIS(kipris.or.kr) 상표 검색** — 다음 세 류를 확인한다.
  - 제9류 (앱)
  - 제35류 (광고업)
  - 제41류 (오락·게임 서비스업)
- **도메인 확보** (`.com` / `.kr`) — 현재 미확보. 배포(`[[deployment]]`)의 도메인/TLS 결정과 맞물린다.

## 구현 규약

사이트명은 `NEXT_PUBLIC_SITE_NAME` **한 곳에서만** 관리한다. 컴포넌트·문구에 **하드코딩하지 않는다** — 이름이 바뀌면 한 변수만 고친다(`[[env-vars]]`).
