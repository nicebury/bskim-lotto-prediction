# 크롤링 방어 — 무엇을 막고 무엇을 막지 않는가

## 결론부터

**당첨번호는 막을 대상이 아니다.** 막으려 하면 잃는 것이 지키는 것보다 크다.

## 왜 막지 않는가

**① 우리 자산이 아니다.** 로또 당첨번호는 동행복권이 공식 발표한 자료를 우리가 정리한 것이다. 우리 화면을 막아도 남들은 원천에서 그대로 가져간다. 막아서 독점할 수 있는 성질의 데이터가 아니다.

**② 이 사이트는 유입이 전적으로 검색이다**([[0002-nextjs-app-router]]). 서버 렌더링, 사이트맵 1,287 URL, "JS 를 꺼도 본문이 보인다" 는 완료 기준까지 전부 **크롤러가 잘 읽게** 만든 장치다. 크롤링 방어의 대부분(JS 렌더링 강제, 봇 차단, 난독화)은 검색 크롤러도 함께 막는다. 애드센스 심사도 같은 크롤러가 한다.

**③ 브라우저에 보이면 가져갈 수 있다.** 완전한 차단은 없다.

## ⚠ 진짜 열린 곳은 HTML 이 아니라 API 다

2026-08-28 실측:

| | 값 |
|---|---|
| `GET /api/lotto/rounds?page=1&size=200` | 200건 · **22ms** |
| 전 회차(1,238) 확보 | **7번 호출 · 0.2초** |
| 백엔드 주소 노출 위치 | 브라우저 번들(`NEXT_PUBLIC_API_BASE_URL`) |

브라우저가 통계·추천·꿈해몽을 백엔드에서 직접 받으므로([[component-boundaries]]) 그 주소는 **공개될 수밖에 없다**(`NEXT_PUBLIC_*` 은 번들에 박힌다 — `frontend/CLAUDE.md`). HTML 을 파싱할 이유가 없다. 깨끗한 JSON 이 더 빠르다.

**그래서 HTML 크롤링 대책을 아무리 세워도 데이터는 지켜지지 않는다.** 순서를 틀리지 않는다.

## 지금 하고 있는 것

**robots.txt 선별 차단**(`app/robots.ts`). 검색에 우리를 실어 주지 않으면서 대역폭만 쓰는 봇 둘만 막는다 — 생성형 AI 학습 수집기와 상업용 SEO 분석 도구.

⚠ `Google-Extended` · `Applebot-Extended` 는 **검색 색인과 무관**하다(각각 Gemini · Apple Intelligence 학습 제어 전용). 막아도 검색 노출은 그대로다. **`Googlebot` · `Applebot` 본체와 혼동하면 사이트가 검색에서 사라진다.**

⚠ `Yeti`(네이버) · `Daum` · `bingbot` · `PetalBot` · `DuckDuckBot` 은 넣지 않는다. **"부하가 크다" 는 이유만으로 검색 봇을 막지 않는다.**

⚠ **robots.txt 는 담장이 아니라 표지판이다.** 지키는 봇만 지킨다.

**이용약관 제5조**에 자동화 수단의 대량 수집 금지를 이미 적어 두었다. 법적 근거는 있고 기술적 강제는 없다.

## 아직 하지 않은 것 — 필요해지면 이 순서로

| 순서 | 조치 | 막는 것 | 대가 |
|---|---|---|---|
| 1 | **브라우저 → 백엔드 직접 호출을 없앤다.** Next Route Handler 로 프록시하고 백엔드는 내부망에만 연다 | 위 실측의 구멍 | 브라우저 호출 7개 재배선, 캐시·타임아웃 재설계 |
| 2 | **Rate limit**(CDN·nginx). IP 당 분당 요청 수 | 대량 수집 속도 | 배포 인프라 몫. 정상 사용자 오탐 주의 |
| 3 | 의심 UA 차단·챌린지 | 지키지 않는 봇 | 검색 크롤러 오탐 시 색인 붕괴 |

1번을 하지 않은 채 2·3번만 하면 효과가 없다.

## 정말 지킬 값어치가 있는 것

당첨번호가 아니라 **우리가 쓴 글**이다.

- 꿈 소재 30편의 민간 해석([[0013-dream-meanings-in-frontend]])
- 회차마다 다른 번호 이력 서술
- 가이드 5편, 통계 해설, FAQ

이것들은 우리가 만들었으므로 저작권이 있고, 원천이 따로 없어 베끼면 곧 표절이다. 다만 **여기에도 기술적 방어보다 표시와 대응이 맞다** — 저작권 표기, 약관 조항, 발견 시 조치. 기술로 막으면 검색엔진도 못 읽어 애초에 쓴 목적이 사라진다.
